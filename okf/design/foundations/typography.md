# Type scale
- carb-figure: 72/1.0, weight 500, tabular-nums, accent
- title: 28/1.2, 500
- body: 18/1.45, 400
- meta: 15/1.4, 400, text-muted
Self-hosted font files (offline). The files are a subset of IBM Plex Sans; the SIL Open Font License doesn't
let a modified copy keep the reserved name 'Plex', so they are named Kitchen Sans inside and out, with IBM's
copyright and the license (OFL.txt) beside them.
